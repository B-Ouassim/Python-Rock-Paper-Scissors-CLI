# 🪨📄✂️ Classic Rock, Paper, Scissors Game (Python)

A simple, command-line implementation of the classic two-player game. This project effectively showcases fundamental **Python programming skills**, including function definition, conditional logic, and the use of the `random` module for generating the CPU's move.

## ✨ Features
* **Three Rounds:** The game runs for a fixed three rounds.
* **Randomized Opponent:** The CPU opponent selects a move randomly, ensuring fair play.
* **Score Tracking:** Tracks the points for both the player and the CPU throughout the game.
* **Final Result:** Declares the winner or a draw once all three rounds are complete.

## 💻 Technology Used
* **Python 3:** Core language used for game logic and execution.

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/YourUsername/Python-Rock-Paper-Scissors-CLI.git](https://github.com/YourUsername/Python-Rock-Paper-Scissors-CLI.git)
    ```
2.  **Run the game:** Open your terminal or command prompt, navigate to the project directory, and execute the file:
    ```bash
    python RockPapperScissors.py
    ```

## 🎮 How to Play
1.  When prompted, enter one of the following characters:
    * `r` for **Rock**
    * `p` for **Paper**
    * `s` for **Scissors**
2.  The game will display the CPU's choice and the current score before proceeding to the next round.
